# Labjac Mods - Minecraft 1.7.10 Forge 模组包

## 项目简介

这是一个基于 Minecraft 1.7.10 Forge 的大型综合模组包，融合了 **Flan's Mod** 载具与武器系统以及 **HFR (Austria-Hungary)** 工业与派系战争系统。该模组包提供了完整的军事、工业、经济和派系战争游戏体验。

## 核心特性

### 🚁 Flan's Mod - 载具与武器系统

#### 载具系统
- **飞机系统**：包含战斗机、轰炸机、侦察机等多种机型
  - 完整的飞行物理模拟（俯仰、偏航、滚转）
  - 自定义 HUD 显示（速度、高度、航向）
  - 多座位系统（驾驶员、炮手、乘客）
  - 起落架、襟翼、后燃器等真实飞行系统

- **地面载具**：坦克、装甲车、卡车等
  - 可自定义炮塔、武器系统
  - 多乘员协同作战

- **机甲系统**：可驾驶的人形机甲
  - 近战与远程武器切换
  - 特殊机动能力

#### 武器系统
- **枪械**：步枪、冲锋枪、狙击枪、机枪等
  - 换弹系统
  - 枪械模式切换（全自动/半自动/点射）
  - 下挂式武器（榴弹发射器等）
  - 瞄准镜系统（热成像、夜视）

- **弹药系统**：多种口径弹药，可配置弹道与伤害
- **内容包驱动**：所有载具和武器通过配置文件定义，支持无限扩展

#### 键位控制（已汉化）
完整的键位绑定系统，支持载具驾驶、武器操作、座位切换等功能。

### ⚔️ Clowder - 派系战争系统

#### 派系基础
Clowder 是本模组的核心派系系统（命名源自猫群的英文"clowder"），允许玩家创建和管理自己的国家/派系。

**基础命令：**
- `/c create <名称>` - 创建派系
- `/c apply <派系名>` - 申请加入派系
- `/c leave` - 离开当前派系
- `/c info [派系名]` - 查看派系信息
- `/c list` - 列出所有派系

#### 领土系统
- **旗帜占领机制**：
  - 放置旗帜（Flag Big）可宣称周围区块为己方领土
  - 旗帜有辐射范围，范围内的区块自动成为派系领土
  - 旗帜需要持续在线玩家维持，否则会逐渐衰退
  
- **占领条件**：
  - 只有在战争状态下才能占领敌方旗帜
  - 占领需要破坏敌方旗帜并在原地放置己方旗帜
  - 占领后立即获得该旗帜控制的所有区块

- **特殊区域**：
  - **安全区（Safezone）**：禁止 PvP 和建造
  - **战争区（Warzone）**：禁止建造但允许 PvP
  - **荒野区（Wilderness）**：无限制区域
  - **派系领土（Faction）**：仅所属派系可建造，队友间禁止 PvP

#### 战争系统

**宣战流程：**
1. **边境摩擦（Skirmish）**：`/c skirmish <目标派系>`
   - 消耗威望值（Prestige）
   - 进入准备期（默认 15 分钟）
   - 目标派系收到警告，可选择投降（`/c retreat`）
   
2. **正式宣战（Declare）**：`/c declare`
   - 准备期结束后，发起方可正式宣战
   - 战争持续时间：默认 60 分钟
   - 战争期间可占领敌方旗帜和领土

3. **先发制人（Preemptive）**：`/c preemptive <派系>`
   - 被宣战方可在准备期内反向宣战
   - 立即进入战争状态

**战争机制：**
- **在线要求**：只有当目标派系有一定数量玩家在线时才能宣战
- **冷却系统**：
  - 投降后有投降冷却期（Retreat Ban）
  - 对同一目标有宣战冷却（Treaty System）
- **加时系统**：`/c overtime` - 进攻方可延长战争时间（一次性）
- **盟友系统**：盟友可以传送支援，但不直接参战

**附庸系统：**
- `/c suckoff <宗主国>` - 成为附庸国
- `/c accepttribute <附庸国>` - 接受附庸
- `/c suppress <附庸国>` - 镇压叛乱的附庸
- `/c revolt` - 附庸国起义独立
- 附庸国受宗主国保护，但需定期进贡
- 对附庸宣战会自动对其宗主国宣战

#### 经济系统
- **派系货币**：每个派系拥有独立的银行账户
- **威望系统（Prestige）**：
  - 威望值用于宣战、建造特殊建筑等
  - 通过占领领土、击杀敌人、建造建筑获得
  - 有威望上限和生成速度上限

#### 传送系统
- `/c home` - 传送到派系主城
- `/c sethome` - 设置派系主城（有冷却）
- `/c warp <名称>` - 传送到派系传送点
- `/c setwarp <名称>` - 设置传送点
- `/c allyhome <盟友派系>` - 传送到盟友派系（需在盟友领土）

### 🏭 HFR - 工业与核能系统

#### 工业机器
- **RF 兼容**：所有机器兼容 CoFHore Redstone Flux 能源系统
- **核能系统**：
  - 核反应堆
  - 核燃料处理
  - 核废料处理
  
#### 武器系统
- **导弹系统**：ICBM、SLBM、巡航导弹
- **核武器**：可配置当量和范围
- **围城武器**：攻城炮、火炮等

#### 月球维度
- 自定义月球维度生成
- 特殊资源和建筑

### 🏘️ 区块宣称与人口系统（新增）

#### 区块宣称系统
基于派系旗帜的区块可以进一步宣称为特定功能区域：

**区域类型：**

1. **居民区（Residential Zone）**
   - 产出：人力、适役人口
   - 建设成本：消耗派系银行金钱
   - 效果：基础人口增长区域

2. **行政区（Administrative Zone）**
   - 产出：人力、政治点数
   - 建设成本：消耗派系银行金钱
   - 效果：提供政治点数用于国策和决议

3. **矿产区（Mining Zone）**
   - 产出：矿物资源
   - 消耗：人力
   - 效果：定时产出可配置的矿物物品

4. **科研区（Research Zone）**
   - 产出：科研点数
   - 消耗：适役人口
   - 效果：用于解锁科技树

5. **工业区（Industrial Zone）**
   - 可建造：军用工厂、民用工厂
   - 效果：提供生产槽位，用于武器和物资生产

**区域命令：**
- `/c claim <区域类型>` - 将当前旗帜区块宣称为指定类型
- `/c unclaim` - 取消区块宣称
- `/c claiminfo` - 查看当前区块宣称信息

#### 人口系统
- **人口增长**：居民区每日按比例产生人口
- **适役人口转换**：普通人口按比例转换为适役人口（受科技树和国策影响）
- **随机产出**：每小时每1000人口概率产出配置项物品
- **配置化**：
  - 所有产出数量可在 YAML 配置
  - 产出时间可自定义
  - 支持 Mod 物品

#### 派系仓库系统
- **命令**：`/c storehouse` - 打开派系仓库 GUI
- **功能**：
  - 存储区块宣称系统产出的所有资源
  - 存储人口系统产出的物品
  - 派系成员共享访问（权限可配置）
  - 支持大容量存储

### 🎯 国策与决议系统

#### 国策树系统（National Focus）
每个派系在创建时选择一个意识形态，并获得对应的国策树。

**意识形态类型：**（可在配置中自定义）
- 民主主义
- 共产主义
- 法西斯主义
- 中立主义
- 自定义意识形态...

**国策特性：**
- 每个国策有前置条件和互斥条件
- 国策提供各种增益：
  - 人口增长速度加成
  - 科研速度加成
  - 工厂效率加成
  - 军事加成
  - 资源产出加成

**命令：**
- `/c policy` - 打开国策系统 GUI
  - 派系领袖和官员：可选择和解锁国策
  - 普通成员：只能查看国策描述和效果

**配置：**
- 国策树完全可配置（YAML格式）
- 每个国策的效果数值可自定义
- 支持添加无限国策节点

#### 决议系统（Decision）
类似钢铁雄心4的决议系统，提供临时增益。

**特性：**
- 消耗政治点数
- 提供持续时间的增益效果
- 可配置冷却时间
- 一次只能激活有限数量的决议

**命令：**
- `/c decision` - 打开决议系统 GUI
  - 消耗政治点数来获得临时增益
  - 查看当前激活的决议
  - 查看决议剩余时间

**决议效果类型：**（可配置）
- 临时工厂效率提升
- 临时人力增长加速
- 临时科研加速
- 战争相关增益
- 经济增益

### 🔬 科技树系统

#### 派系科技树
每个派系拥有独立的科技树进度。

**科技特性：**
- 科技有前置科技要求
- 科技有研发时间和科研点消耗
- 未解锁的科技中物品无法使用
- 科技提供各种解锁和加成：
  - 解锁物品使用权限
  - 解锁建筑
  - 提高生产效率
  - 解锁新的生产项目

**科技队伍系统：**
- 派系创建时自动创建科技队伍
- 玩家加入派系时自动加入科技队伍
- 共享已解锁的科技权限

**命令：**
- `/c tech` - 打开科技树 GUI
  - 派系领袖和官员：可选择研发科技
  - 普通成员：查看科技进度和效果

**配置：**
- 完全 YAML 可配置
- 支持自定义科技节点
- 支持自定义科技效果
- 支持 Mod 物品解锁

### 🏭 生产系统

#### 工厂系统
- **民用工厂**：在工业区建造，提供民用生产槽位
- **军用工厂**：在工业区建造，提供军用生产槽位

**槽位机制：**
- 每达到一定数量的工厂增加一个生产槽位
- 国策树可提供额外槽位
- 决议可临时增加槽位
- 科技树可提高槽位效率

#### 生产命令
- `/c produce` - 打开生产系统 GUI
  - 查看可生产项目
  - 设置生产项目和数量
  - 查看生产进度

**生产特性：**
- 支持武器、载具、物资生产
- 支持"奇迹武器"生产（特殊科技解锁）
- 生产时间、成本、产出可配置
- 可设置科技树前置条件
- 通过派系影响力和经济号召人口参与生产

#### 生产配置
- 完全 YAML 可配置
- 每个生产项目可设置：
  - 所需工厂类型和数量
  - 科技前置条件
  - 原材料消耗
  - 生产时间
  - 产出物品和数量
  - 支持 Mod 物品

### 📋 配置系统

所有系统的数值都可以通过 YAML 配置文件自定义：

**配置文件位置：**
```
config/hfr/
├── zones.yml          # 区域配置
├── population.yml     # 人口系统配置
├── policies.yml       # 国策树配置
├── decisions.yml      # 决议配置
├── technologies.yml   # 科技树配置
└── production.yml     # 生产系统配置
```

## 技术架构

### 模组结构
```
src/main/java/
├── com.flansmod/          # Flan's Mod 核心
│   ├── client/            # 客户端渲染、HUD、输入处理
│   ├── common/            # 通用逻辑
│   │   ├── driveables/    # 载具系统
│   │   ├── guns/          # 枪械系统
│   │   ├── teams/         # 团队系统
│   │   └── network/       # 网络包
│   └── api/               # API 接口
│
└── com.hfr/               # HFR 核心
    ├── blocks/            # 方块定义
    ├── items/             # 物品定义
    ├── tileentity/        # 方块实体
    │   ├── machine/       # 机器
    │   ├── clowder/       # 派系相关方块
    │   └── prop/          # 装饰方块
    ├── clowder/           # 派系系统
    │   ├── Clowder.java           # 派系核心类
    │   ├── ClowderTerritory.java  # 领土系统
    │   ├── ClowderFlag.java       # 旗帜系统
    │   └── events/                # 派系事件
    ├── command/           # 命令系统
    ├── data/              # 数据持久化
    ├── entity/            # 实体
    ├── inventory/         # GUI 和容器
    ├── packet/            # 网络通信
    └── render/            # 渲染
        └── hud/           # HUD 渲染
```

### 数据持久化
- 派系数据存储在 WorldSavedData 中
- 领土数据使用 HashMap 存储区块归属
- 支持服务器重启后数据恢复
- 定期自动保存

### 事件系统
- 使用 Forge 事件总线
- 自定义派系事件（领土变更、战争状态等）
- 支持其他模组监听和交互

### 网络同步
- 客户端-服务端数据同步
- HUD 实时更新
- 领土边界可视化

## 配置与内容包

### Flan's Mod 内容包
内容包位于 `Flan/` 目录，使用文本文件定义：
- 载具类型（Plane, Vehicle, Mecha）
- 枪械类型
- 弹药类型
- 皮肤和贴图

### HFR 配置
主配置文件：`config/hfr.cfg`
- 派系系统参数（威望、宣战时间等）
- 工业系统参数
- 经济系统参数

### 新增配置文件（config/hfr/）
- `zones.yml` - 区域类型和产出配置
- `population.yml` - 人口增长和转换率
- `policies.yml` - 国策树定义
- `decisions.yml` - 决议定义
- `technologies.yml` - 科技树定义
- `production.yml` - 生产项目定义

## 游戏玩法提示

### 新手派系指南

1. **创建派系**：
   ```
   /c create 你的派系名
   ```

2. **设置主城**：找一个安全的地方
   ```
   /c sethome
   ```

3. **建立领土**：
   - 制作并放置旗帜
   - 旗帜周围区块自动成为你的领土

4. **宣称功能区**：
   - 站在旗帜旁边使用 `/c claim residential` 设置居民区
   - 继续建立其他功能区

5. **发展经济**：
   - 居民区产生人口和人力
   - 行政区产生政治点数
   - 矿产区采集资源
   - 科研区研发科技
   - 工业区建设工厂

6. **解锁科技**：
   - `/c tech` 查看科技树
   - 使用科研点解锁新科技

7. **制定国策**：
   - `/c policy` 查看国策
   - 选择适合你的发展路线

8. **建立生产**：
   - 在工业区建造工厂
   - `/c produce` 开始生产武器和装备

9. **准备战争**：
   - 与其他派系结盟
   - 积累威望值
   - 生产武器和载具
   - 对敌对派系发起边境摩擦

### 战争技巧

1. **选择时机**：确保你有足够的在线成员
2. **情报侦察**：使用 `/c info <派系>` 了解敌人实力
3. **快速占领**：战争开始后立即占领关键旗帜
4. **防御准备**：在己方领土建立防御工事
5. **盟友协同**：邀请盟友传送支援

### 经济发展

1. **平衡发展**：不要只建一种区域
2. **人口优先**：先建立足够的居民区
3. **科技重要**：早期投资科研区加速发展
4. **工业基础**：工厂是后期力量的保证

## 已知问题

- 在非主世界（非维度 0）使用派系命令会报错
- 大量旗帜可能导致服务器性能下降
- 跨维度传送可能不稳定
